# Blind 75 — Data Structures & Algorithms

Personal repository tracking my solutions and progress through the **[Blind 75](https://neetcode.io/practice/practice/blind75)** roadmap via **NeetCode**. 

The goal of this repository is to systematically master core algorithmic patterns, optimize time/space complexities, and maintain a documented archive of my technical interview preparation.

---

##  Objective & Methodology

The **Blind 75** is a curated list of high-yield algorithmic problems designed to cover the fundamental patterns required for technical software engineering interviews:

- **Pattern Mastery:** Focus on problem-solving paradigms (Two Pointers, Sliding Window, Dynamic Programming, Graphs) rather than memorizing individual solutions.
- **Complexity Analysis:** Striving for optimal time ($O$) and space ($O$) trade-offs across all implementations.
- **Continuous Tracking:** Synced directly via NeetCode's GitHub integration to maintain an active log of iterations and improvements.
